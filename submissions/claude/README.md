# Ponko Engine

Official engine documentation and workflows for creating, inspecting, and profiling Ponko games. Start with the `ponko` skill and its documentation map. Match documentation to your game's engine revision.

This directory bundle contains instructions only. It does not register or launch an MCP server or run installation scripts. Runtime inspection requires an MCP connection configured separately by the user in a supported local client. The workflows check tool availability before use.

For optional runtime setup and full host plugins, see https://github.com/ponkoengine/ponko-plugins#readme.

Icon: official Ponko favicon from https://ponko.dev/favicon.svg, rasterized for the directory's PNG requirement.
